All fourteen voicepacks now use one installer for BG:EE, BG:EE with Siege of
Dragonspear, BG2:EE, and EET (EE 2.6 soundset layout or a compatible later version).

- Fixed Amelyssan and Gromnir's BG2/EET-only installation restriction.
- Added consistent game/layout checks and the selected game-language sound folder.
- Kept every recording, subtitle, and curated assignment unchanged.
- Added a shared rebuild recipe and automated installer compatibility checks.

Download the ZIP for the voice you want, extract it into the game directory,
and run its setup executable. The recordings and subtitles remain English.
For an existing installation, close the game and choose Reinstall in WeiDU;
WeiDU may also reinstall mods installed after that pack.

BG:EE 2.6 does not trigger the two rare action slots, and common selection 7 is
documented as inactive in the 2.6 games. Assigned-slot counts include those
registrations. The 1998 original BG1 and pre-2.6 layouts are not supported.

Validation: 84 pack installations across six game/language fixtures, all 556
assignments checked per fixture, reinstall/uninstall restoration, 42 invalid-target
checks, unchanged audio bytes, deterministic ZIPs, and a clean Defender scan.
Live BG:EE listening/playtesting remains pending.
